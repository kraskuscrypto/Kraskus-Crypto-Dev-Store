# Bitcoin SV by Kraskus 0.6.1

Bitcoin SV mainnet node and solo Stratum controller, with external payout address and a required1% developer fee paid directly in the coinbase. SV Node1.2.2 and the existing chain configuration are retained. Simple Home, Mining, Blocks, Blockchain and Settings pages; themes, live worker telemetry and safe pruning controls. No user-facing native wallet. Existing wallet files are preserved during migration. Mining starts paused and requires separate setup and activation. Kraskus Pool forwarding is under development. Software regtest qualified; no physical-miner qualification is claimed for this release.

Upgrade only with the protected migration kit. Existing chain paths remain unchanged; wallet data and funds are retained. Both apps remain stopped after migration. No seed or private key is requested by the app.
