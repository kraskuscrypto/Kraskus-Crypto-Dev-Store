# XBT by Kraskus 0.3.0

XBT solo mining on the existing Bitcoin Knots BLAKE2b fork (activation height961640), not ordinary Bitcoin SHA-256. External payout address with a required1% developer fee paid directly in the coinbase. Node-derived coinbase maturity is retained, including the long-maturity rule. Simple Home, Mining, Blocks, Blockchain and Settings pages; themes, live worker telemetry and safe pruning controls. No user-facing native wallet. Existing wallet files are preserved during migration. Mining starts paused and requires separate setup and activation. Kraskus Pool forwarding is under development. Software regtest qualified; no physical-miner qualification is claimed for this release.

Upgrade only with the protected migration kit. Existing chain paths remain unchanged; wallet data and funds are retained. Both apps remain stopped after migration. No seed or private key is requested by the app.
